## Deliverables

- `examples/*.example.json` — valid schemas, fictional “Teddy & Lilly” household; owner ids come from `goals.owners[]` (example: `teddy` / `lilly`).
- `docs/setup-with-ai.md` — LLM playbook (one question at a time; write files; run builds; wire automation).

- README link to SETUP.

- Owner ids are household-chosen slugs (not fixed `kevin`/`hanna` in application code).
