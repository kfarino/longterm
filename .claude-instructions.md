# Claude Instructions for Family Folder

## Workflow Rules

When working in this folder, ALWAYS follow these steps:

1. **Check To-Do.md first** - Read the current to-do items and their status
2. **Navigate to specific project folders** - Each to-do item has its own folder
3. **Update the main To-Do.md** - When making changes to any project, update the status in the main list
4. **Link everything** - Maintain links between the main To-Do.md and individual project folders
5. **Keep it organized** - Each to-do item gets its own folder with all related files

## Structure

```
Family/
├── .claude-instructions.md (this file)
├── README.md (overview and usage)
├── To-Do.md (main task list with links)
└── [Project Folders]/ (one folder per to-do item)
    ├── notes.md
    ├── files...
    └── status.md
```

## When Adding New Tasks

1. Add the task to To-Do.md
2. Create a new folder with a descriptive name
3. Add a link in To-Do.md to the new folder
4. Create initial files in the new folder
