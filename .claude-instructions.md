# Claude Instructions for Family Folder

## Workflow Rules

When working in this folder, ALWAYS follow these steps:

1. **Check TASKS.md first** - Read TODAY section for immediate actions
2. **Update daily** - Date-stamp updates, move completed items to ✅ COMPLETED section with dates
3. **Navigate to project folders** - Detailed files in Nikola/, Finances/, etc.
4. **Keep TASKS.md actionable** - Use checkboxes [ ], clear next actions, date-driven priorities
5. **Mirror work structure** - Timeline view, TODAY/THIS WEEK/HEADS-UP sections, blockers tracking

## Task Management Style

**Daily Focus:**
- TODAY section with high-priority checkboxes
- THIS WEEK grouped by project with clear owners
- HEADS-UP for 2-4 week visibility
- BLOCKERS section for dependencies
- COMPLETED section with dates

**Priority Indicators:**
- 🚨 Urgent (today/tomorrow)
- ⚠️ Important (this week)
- 🔄 In progress
- 🔴 Blocked (needs something first)
- 🤔 Decision needed
- ✅ Completed

## When Adding New Tasks

1. Add to appropriate section in TASKS.md (TODAY/THIS WEEK/HEADS-UP)
2. Include owner (Kevin/Hanna/Both), due date, clear next action
3. Link to detailed files in project folders if complex
4. Update TIMELINE view if milestone-driven
5. Move to ✅ COMPLETED with date when done
